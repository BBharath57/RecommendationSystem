# RecommendationSystem

Built a Movie Recommendation System which give top movies which are similar.
Used content based filtering 
Used Knn for find near neighbors for similar movies 

ex: for Top Gun 
These are the similar i got:
Top Gun (1986)
Jurassic Park (1993)
True Lies (1994)
Speed (1994)
Die Hard: With a Vengeance (1995)
Batman (1989)
Die Hard 2 (1990)
Star Trek IV: The Voyage Home (1986)
Clear and Present Danger (1994)
GoldenEye (1995)
